# JavaScript: laços de repetição

`for`, `while` e `do...while`.

| Exercício | O que pratica |
|---|---|
| [Laço for](for.html) | Contador simples. |
| [Laço while](while.html) | Contagem regressiva de 10 a 1. |
| [Laço do...while](do-while.html) | Repete até receber um número e lista os pares. |
| [break e continue](interrupcao.html) | Dobro para pares e triplo para ímpares; 0 para sair. |
| [Contas do mês](contas-do-mes/index.html) | Contador e acumulador. |
| [Fábrica de estrelas](fabrica-de-estrelas/index.html) | Alterna símbolos conforme a posição. |
| [Tabuada](tabuada/index.html) | Tabuada de 1 a 10. |
| [Números primos](numeros-primos/index.html) | Verificação com variável de controle. |
| [Repete fruta](repete-fruta/index.html) | Concatenação dentro do laço. |

## Correções aplicadas

- **Laço while:** Variável com nome digitado errado; o resultado ficava sempre 0.
- **break e continue:** A mensagem dizia "dobro" ao mostrar o triplo.
- **Contas do mês:** O total ficava sempre R$ 0,00; A lista aparecia repetida no total; Caminhos de arquivos.
- **Fábrica de estrelas:** Caminhos de arquivos.
- **Tabuada:** A página não encontrava o JavaScript.
- **Números primos:** Caminhos de arquivos.
- **Repete fruta:** Caminhos de arquivos.
