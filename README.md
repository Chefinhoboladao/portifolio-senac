- Páginas: baixe o repositório e abra o arquivo `index.html` no navegador.
- Programas de terminal: instale o [Node.js](https://nodejs.org) e siga o README da pasta.

## Sobre este repositório

Os exercícios foram revisados com ajuda de IA: erros foram corrigidos, alguns itens incompletos foram terminados e arquivos repetidos foram unificados. Cada pasta lista o que mudou.

Banco de dados também faz parte do curso; o material dessas aulas é do professor e por isso não está copiado aqui.
